# Recommendation Design

The MVP uses transparent scoring.

- Course/degree match: 25
- Branch match: 30
- Specialization match: 15
- Location match: 20
- NIRF information available: 5
- NAAC information available: 5

Maximum: 100.

This is a prototype scoring mechanism, not a validated measure of university quality.
Production should establish domain-approved weights and evaluate ranking quality with real user preference data.
